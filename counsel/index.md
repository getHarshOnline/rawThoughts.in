# Counsel

Counsel helps when rules establish what is allowed but cannot settle which choice is best. [Pale](https://rawthoughts.in/pale/) asks Counsel's Judgment Host for advice from a small, local model. Its separate Memory host helps Scope find useful context, using a model chosen for that different task.

<a id="intelligence-chosen-for-the-work"></a>

## Intelligence chosen for the work

Among [the products](https://rawthoughts.in/products/), Counsel judges where rules leave a choice. It has two jobs and two callers. When an agent is about to act and Pale's rules allow several choices, Pale asks its Judgment Host which to try first; when Scope searches for context, the Memory host helps find passages by meaning, with Pale or, over Weave, without it. [Work through a recommendation](https://rawthoughts.in/counsel/frame-a-judgment/) to see what Counsel needs from Pale. [Find a maintenance procedure](https://rawthoughts.in/counsel/memory-artifacts/) to see how its separate memory service helps Scope. No host runs yet; the guide follows one recommendation through the design. Each recommendation is kept in Pale's history of the work, which Reckon later learns from. The person or system responsible for the decision still decides what to do.

## From a question to useful judgment

When the evidence leaves more than one explanation open, Counsel can propose the question that tells them apart. Whether to act on the advice or ask a person follows the caller’s rules.

1. 
   
   <a id="frame-the-question"></a>
   
   ### Frame the question
   
   Name the decision, the choices Pale allows and the records the model can read. Set the time and resource limits for the answer.

2. 
   
   <a id="interpret-the-evidence"></a>
   
   ### Interpret the evidence
   
   Ask which records support each choice and what remains unclear. The model can work only with the records it is given.

3. 
   
   <a id="get-advice-or-a-better-question"></a>
   
   ### Get advice or a better question
   
   Read the recommendation, ranking or question alongside the records. The model can also say it has too little information to choose.

4. 
   
   <a id="make-the-decision"></a>
   
   ### Make the decision
   
   Follow, reject or escalate the advice through the usual process. Keep what the model said, what you decided and what happened afterward.

## Questions about Counsel

**Are recommendations and retrieval the same service?**

They are two services. The Judgment Host compares the choices Pale provides. The Memory host helps [Scope](https://rawthoughts.in/scope/) find, connect and summarise permitted records. Each has its own models, permissions and tests.

**How is a model chosen?**

Start with the work and hardware the model will use. Compare answer quality, when it knows to abstain, how long it takes and how much memory it needs. [Understand a model and its improvement](https://rawthoughts.in/counsel/models-and-improvements/) explains that process. [MUON](https://causality.in/muon/) studies a possible adaptive successor to the local judge, while [HENA](https://causality.in/hena/) explores how many such units could work together. Either would still work inside Pale, which keeps governing permissions and resources.
